# Project instructions

This repository contains a web prototype built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` — Main entry point.
- `style.css` — Styles.
- `app.js` — JavaScript functionality.
- `assets/` — Images, icons, fonts, and other assets.

## Development rules

1. Always modify the existing project files. Do not create a separate project directory.
2. Keep `index.html` in the repository root.
3. Preserve relative paths between HTML, CSS, JavaScript, and assets.
4. Do not create a `dist/` directory unless explicitly requested.
5. Do not introduce frameworks, dependencies, or build tools without approval.
6. Keep the prototype compatible with GitHub Pages at `https://sjassim.github.io/prototype/`.
7. Verify that existing functionality continues working after changes.
8. Do not modify the Git configuration or GitHub Pages deployment settings.

## Workflow

- Make changes directly in the current project.
- Summarize which files were modified.
- Leave committing and pushing to GitHub to the user unless explicitly requested.
